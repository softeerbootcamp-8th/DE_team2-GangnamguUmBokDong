# 1. 결정 제목을 여기에 작성

Proposed

## Context

이 결정이 필요한 배경과 상황을 서술합니다.
어떤 문제가 있었는지, 어떤 제약(기술적/조직적/시간적)과
고려해야 할 요소들이 작용했는지 적습니다.

결정 자체보다 "왜 이 결정을 내려야 했는가"의 맥락이 핵심이며,
시간이 지나 이 문서를 다시 볼 사람이 당시 상황을 이해할 수 있도록 씁니다.

## Decision

우리가 무엇을 하기로 결정했는지 명확하게 서술합니다.
"우리는 ~하기로 한다(We will ...)" 형태의 능동적 문장으로 작성합니다.

## Consequences

이 결정으로 인해 발생하는 결과를 서술합니다.
좋아지는 점, 나빠지는 점, 그리고 감수해야 하는 트레이드오프를
모두 정직하게 기록합니다.

- 긍정적: ...
- 부정적: ...
- 중립적/후속 고려사항: ...
