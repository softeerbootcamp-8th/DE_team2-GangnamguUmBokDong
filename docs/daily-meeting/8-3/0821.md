### 종민:

- 챔피언보다 나은 모델 중에서 선택

EC2, EMR 분리

- EC2 : 학습

- EMR : 피처마트 생성

    - 학습 프로필 : 파라미터 지정해놓은 세팅

DAG 

- EC2 → 현재 모델 성능 평가

- 성능 미달 → EC2 종료 → EMR 

- 재학습 → EMR 종료 → EC2

- 평가 → 비교 → 교체 → 반복

- 더 좋은 모델 또는 학습 프로필 다 소모할 때까지
