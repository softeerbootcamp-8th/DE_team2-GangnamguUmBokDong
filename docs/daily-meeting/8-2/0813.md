## 5. collector

api 호출 하나가 실패해서 재시도 소진하면 실행이 끝내고 다시 처음부터 실행.

한 작업에서 몇 조각을 실패할 경우 일단 끝까지 돌다가 버리지 않고 재시도할 때 실패한 조각을 다시 받게 수정

- 브론즈가 다 받아야 실버를 진행

- 실패한 브론즈가 생긴다.

몇 조각 실패하면 실패한 조각 빼고 실버까지 진행

- 최대 실패 비율은 조절 가능하게 설정



- 이후 실패한 작업은 24시간마다 백필

    - 지난 1주일 것 채워넣기

- DAG 끝나면 결과 airflow에 보고할때 실패한 페이지까지 보고

    - airflow 상에서 저장후 백필

- 하루에 한번 새벽 시간에 5분 작업과 병행해서 백필 진행.
