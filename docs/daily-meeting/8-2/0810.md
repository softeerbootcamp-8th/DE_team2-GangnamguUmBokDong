## 2. 아키텍처 확정

API로 데이터 호출 (EC2) → 

브론즈 데이터로 S3에 저장 → 

직후 EC2에서 정제해서 실버 데이터로 S3에 저장 → 

S3의 데이터 중 필요한 데이터만 빼서 추론 모델로 이동 → 

모델 추론 전에 5분 단위 데이터 합치고, 합친 것 이용 모델 추론

모델 추론 결과와 합친 데이터 모두 S3에 실버 데이터로 저장 → 

실버 데이터 중 서빙 DB(postgresql)에 올릴 데이터 선정 → 

서빙 DB(postgresql)에 골드 데이터 올림 → 

백엔드 api가 골드 데이터를 15초마다 폴링 → 

대쉬보드에 데이터 표시 (5분마다 갱신)
