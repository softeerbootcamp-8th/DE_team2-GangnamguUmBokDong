## 3. 의사결정
### 인구 격자와 주요장소가 서로 겹치는 구간에서 어떻게 실시간 인구를 계산할것인가?
면적이 큰 주요장소부터 비율을 적용한다.

    예) 인구 격자 3번에 4개의 주요장소가 겹치는 경우

    인구 격자 3번 : 4천명, 62,500m^2

    주요장소A 30km^2 → 인구 격자의 15% 차지 : 1m^2당 3백명

    A와 B가 인구 격자안에서 인구 격자의 10% 겹침

    주요장소B 10km^2 → 인구 격자의 20% 차지 : 1m^2당 2백명

    주요장소C 20km^2 → 인구 격자의 25% 차지 : 1m^2당 1백명

    주요장소D 15km^2 → 인구 격자의 30% 차지 : 1m^2당 2.5백명

    겹치지 않은 구역 10%

    면적이 큰 순으로 적용 A - C - D - B
    - A 적용 : 62500의 15% → 9875, 9875*3백 완전 대체

완전 대체로 선택

- 도시데이터에서 주는 데이터가 더 실시간성을 반영한 정확한 데이터일 것이다.

- 서울시에서 인구 밀집 차이가 거의 없는 곳을 대상으로 주요 장소를 결정 했을 것이다.

평균대체를 선택하지 않은 이유

- 실시간 인구 데이터의 면적 내에서 인구 밀도가 일정하지 않으므로 왜곡이 있을 수 있다.

- 우리의 자체 격자 예측이 실시간 도시데이터의 외곽 지역을 인구 밀도가 같다는 가정하에 일괄적으로 자른 것보다 해당 격자에 대해서 더 정확할 수도 있다.

 

### 문화행사정보와 공연정보
