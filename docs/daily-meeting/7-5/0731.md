2. 분야 별로 데이터 나누기



문제

서울 전지역의 실시간 인구 데이터가 없다!

 121곳의 행사도 반영된 미래 데이터와 실시간 데이터 존재 : 도시 인구데이터

4일전만 있지만 전체가 있는 데이터 : 행정동 인구데이터



해결 방법

종민 : 121곳이 아닌 곳은 인구예측 모델을 만들어서 4일전까지 데이터로 오늘의 실시간 인구를 예측하고, 121곳은 도시 인구 데이터로 사용한다.

a. 인구 예측 모델을 학습으로 만들어서 예측하자.

학습 모델이 아니라 최근 4주간의 동일 지역 인구 평균으로 예측하자

인구수의 변화는 크지 않고 대략 일치하기 때문이다.

최근 상태를 반영하기 용이하다.

용선 : 도시 인구데이터가 알려주는 121곳의 대여소만 예측한다.

121곳과 겹치는 대여소가 30%밖에 없다.

121곳에서만 인구수로 예측하고 나머지 70%는 인구말고 날씨 등으로 예측한다.

→ 결론: 121 데이터는 실시간 API로 받아오고, 행정동별 인구(실시간 제공하지 않는 데이터)는 4주동안 평균치를 계산해 채워넣는다.



121곳 이외의 실시간 인구를 과거 데이터로 추산해서 사용한다. 121곳은 도시데이터를 사용.

실시간/미래 인구(장소)와 실시간/미래 날씨를 수요예측 모델에 넣으면 실시간/미래 수요가 결과로 나온다.

실시간/미래 수요예측과 실시간 대여소 현황을 조합해서 우선순위 도출한다.
